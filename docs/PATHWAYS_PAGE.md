# Saved pathways and policy impact

The `#pathways` page groups existing saved evidence without running research or
creating a new profile. It depends on the profile-page navigation introduced in
PR20. Exact saved updates open at `#pathways/update/<encoded event ID>` and reuse
the existing result, calculation and official-source components.

- C20 appears under work permits as a potential option or the actual saved state.
- Express Entry comparisons are policy impact, never an additional pathway.
- Registered requirement checks retain their actual program names and scope.
  The implemented CEC work-interval check is grouped under permanent residence;
  unknown registry categories use the neutral program-requirements heading.
- Saved updates use the existing event timestamps. This page does not claim
  automatic monitoring, scheduled delivery or a comprehensive pathway catalog.

Reads use the existing Guide profile/journey and policy/assessment endpoints.
An explicitly available fictional demo remains separate. Failed personal reads
never fall back to demo findings. Loading, blocked operations, changed employment,
Guide revision, date and calculator version withhold current result claims.
Refresh reads saved data only; it never resends a model request. All unresolved
events remain visible in the saved-updates list.

Existing editors remain mounted across workspace routes so drafts, confirmation
controls and pending-operation guards are preserved. The page uses the approved
profile document surface, Maple theme variables, section dividers and restrained
policy-impact grouping. Mobile navigation scrolls horizontally when necessary.

The private recording preview is outside version control. It reuses the existing
staged scenario at its recorded assessment date, explicitly marks demo context,
and never writes the scenario into personal Guide storage.
