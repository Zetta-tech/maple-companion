# Self-hosted Maple fonts

Latin variable fonts matching Maple Newsletter's Inter and Space Grotesk families. Downloaded from official Google Fonts on 2026-10-25. SIL Open Font License 1.1 texts are included alongside each binary.

- Inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Space Grotesk: https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2
- Licenses: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/google/fonts/tree/main/ofl/spacegrotesk

CSS uses font-display: swap and system fallbacks. No external font request is made at runtime.
